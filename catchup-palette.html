이 문서는 결정론적, 모델 기반, 인간 중심(HITL) 가드레일을 포함한 에이전트 보호 방법론 및 그 검증 평가 과정에 대해 설명합니다.
Streamlit 적용 가이드
.streamlit/config.toml에 아래 내용을 넣으면 바로 적용돼. 추가로 st.markdown()으로 CSS 오버라이드하면 태그/카드 스타일까지 커스텀 가능. 
# .streamlit/config.toml

[theme]
primaryColor = "#C4553A"
backgroundColor = "#FDF8F3"
secondaryBackgroundColor = "#F5EDE4"
textColor = "#3D2E24"
font = "sans serif"
CSS 오버라이드 (태그, 카드, 버튼 등):
# ui/styles.py — st.markdown()에서 inject

CUSTOM_CSS = """
<style>
/* 사이드바 */
[data-testid="stSidebar"] {
    background-color: #FAF4ED;
}

/* 버튼 hover */
.stButton > button:hover {
    background-color: #A8432C;
    border-color: #A8432C;
}

/* 태그 칩 공통 */
.tag-chip {
    padding: 4px 12px;
    border-radius: 20px;
    font-size: 0.78rem;
    font-weight: 500;
}

/* 노트 카드 */
.note-card {
    background: #F5EDE4;
    border-left: 3px solid #EACFC5;
    border-radius: 10px;
    padding: 16px;
}

/* 성공 메시지 */
.success-msg { color: #5B8C5A; }
</style>
"""
